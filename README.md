# mealtracking

食材在庫管理・大人用献立提案アプリ（開発中）。

## 現在のスコープ

2026年8月、離乳食トラッキング機能（M1〜M3）から以下へスコープを再定義しました。

- 食材在庫管理
- 大人用献立提案
- 週間献立表（`mealtracking-app/`のWeeklyMenuScreenを起点に発展）
- ぴよログ連携

詳細な設計判断・実装計画は `docs/` ディレクトリ（`docs/README.md`から参照）を参照してください。
